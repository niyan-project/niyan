# Security policy

## Supported versions

Niyān has not yet published a stable v1 release. Security fixes currently target the latest code on `main` and the newest published pre-release. Older development snapshots are not maintained.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or chat. Use GitHub's private vulnerability reporting flow at <https://github.com/aryan-f/Niyan/security/advisories/new>. If GitHub does not offer that form to your account, use the private contact method listed on the repository owner's profile. Include the affected component and version, impact, reproduction steps or a proof of concept, and any suggested mitigation. Remove real credentials, access tokens, signed URLs, and private dataset content from the report.

Maintainers will acknowledge a report when practical, investigate its scope, coordinate a fix and release, and credit the reporter if requested and safe. Response and release timing depend on severity and maintainer availability; this community project does not promise a formal service-level agreement.

If a live credential was exposed, revoke or rotate it immediately. Reporting the software defect does not invalidate a leaked credential.

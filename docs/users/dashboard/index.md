# The user dashboard

Open the HTTPS address supplied by your administrator and sign in with your Niyān username and password. The dashboard provides browser-based dataset work and the controls associated with your account.

## Main navigation

- **Datasets** lists the repositories visible to your account and lets authorized users create one.
- **Groups** lists the organizational groups you can see and lets authorized users create root groups or nested subgroups.
- The user button in the upper-right opens **Settings** and **Log out**.
- Staff with system permissions also see **System**, which is documented in the operator guide.

## Dashboard guide

1. [Create, browse, upload, and commit dataset files](/users/dashboard/datasets).
2. [Understand groups, membership roles, and dataset grants](/users/dashboard/groups-and-access).
3. [Change account details and create or revoke access tokens](/users/dashboard/account-security).

The dashboard and CLI are complementary. A commit created in the browser is normal Git history and appears in the next CLI pull; a CLI push appears in the dashboard immediately.

# Support

Niyān is a community project maintained on a best-effort basis without guaranteed response or resolution times.

Use GitHub issues for reproducible bugs and focused feature proposals. Include the Niyān version or commit, deployment method, operating system, relevant Git and Git LFS versions, expected behavior, observed behavior, and the smallest safe reproduction. Redact credentials, tokens, signed URLs, database addresses, and private dataset content.

Questions that can be answered by the specifications or component READMEs may be closed with a link to the relevant documentation. Vulnerabilities belong in the private process described by [SECURITY.md](SECURITY.md). Conduct concerns follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
